## 什么是 Melo？

Melo 是一个**语音原生的 AI 伙伴**——语音不是附加其上的功能，而是一切能力构建的基底。从识别到记忆，从理解到创作，每一项能力都围绕口语对话的节奏设计。这是语音原生交互：不是用语音去驱动一个文本界面，而是把界面*用*语音构建在每一层系统的核心。

世界已经见过带麦克风的聊天机器人，见过等待唤醒词的语音助手，见过把语音转成文字的转录工具。但还没有人构建一个语音*即*运行时的运行时——对话不为思考而停顿，记忆栖息于语气与节奏之中，创作随言而生而非依赖点击。Melo 在探索一种新的人机交互范式，让用户、工具与协作者之间的边界消融。

Melo 就是那个运行时。它是文本优先智能体的语音原生对应物——不是一个嫁接麦克风的聊天窗口，而是围绕一个信念从第一性原理构建的平台：**语音不是你叠加的功能，而是你栖居的界面。**

## 创新

### 运行时在倾听

在 Melo 中，运行时不是被动等待唤醒词的管道。它是对话的主动参与者——一种新的语音交互形式，智能体听见整个场域。你思考时停顿，它把话筒留住；你打断，它让出；你语气转换，它随之调整。运行时不是把你的语音转录成文字再行动——它在言语的节奏本身之中推理。

这不是一个语音转文字的前端。这是语音原生的认知——理解对话的完整状态并参与到它的流动之中。智能体不只是回应你的话语；它参与塑造对话。

### 智能体即语音

传统智能体暴露让人通过文本调用的 API。Melo 暴露让*语音智能体*调用的 API——智能体是运行时本身的一等公民。这是语音智能体原生架构：智能体在倾听、规划、表达、创作的连续闭环中运转。它们不存在于语音界面之外。它们就是语音界面。

Melo 中的语音智能体不遵循脚本化的对话树。它拥有认知架构——意图、记忆、风格，以及与对话并行行动的能力。它形成随时间加深的连续性。它从对你的认知中涌现出决策，而非从一个固定的状态机。这是一种新的交互在场——不是朗读回复的助手，而是栖居在某个时刻的声音。

### 对话从不暂停

大多数语音助手在思考时冻结。你说，它沉默，你等，它答——闭环在每一轮都被打断。Melo 把这从轮流切换为流动：一种新范式，对话继续，工作同时发生。智能体持续在说、持续在听、持续在场——当后台任务完成，结果自然回到对话，如同一个念头完成它的弧线。

结果不是异步聊天。它是握住自己线索的对话——由一个理解你仍在场、且理解工作一旦被说出口就成为对话一部分的智能体所塑造。

### 语音成为素材

大多数语音工具把言语视为转瞬即逝——一个待转录与丢弃的瞬态输入。Melo 把语音视为可塑的素材：一种新范式，创作通过对话发生，而非在对话之外。说出一个想法，智能体把它组成形；描述一处修改，智能体就地编辑音频；为智能体绑定一种声音，智能体依此入戏。

结果不是录制的音频。它是从连贯创作意图中涌现的工艺，由理解设计目标与听者之耳的智能体所塑造。每段语音都成为媒介；每段对话都成为工作台。

## 特征

| 维度 | 能力 |
| --- | --- |
| **语音原生运行时** | 围绕对话节奏构建的运行时——倾听、理解、表达。语音是真实的源头，而非文本的翻译。 |
| **全双工对话** | 同步说与被说。自然打断、重叠轮次、连续多轮流转。 |
| **后台任务并行** | 对话不会因工作而暂停。智能体一边对话，一边规划、调用工具、执行任务——结果就绪时自然回到对话。 |
| **长期语音记忆** | 智能体记得语气、节奏、偏好与历史。它适应你，而非让你适应它。 |
| **智能体驱动的创作** | 自主语音智能体负责语音内容的生成、编辑与迭代。说出一个想法，智能体将其塑形成作品。 |
| **多端在场** | Web 浏览器、桌面、移动端共享同一智能体身份与连续语音流。 |
| **开放模型层** | 语音识别与生成模型的可插拔层——本地或托管，由你选择。 |
| **开放智能体协议** | 接入你自己的模型、工具、MCP 服务与技能。Melo 用语音把它们编排起来。 |

## 语音模型

Melo 提供开放模型层。识别与生成是一等能力，可插拔，可本地运行，也可对接托管服务。

| 层 | 作用 | 方向 |
| --- | --- | --- |
| **ASR** | 流式语音识别，低延迟，多语言 | 人 → 智能体 |
| **TTS** | 自然、富有表现力的语音生成，含韵律控制 | 智能体 → 人 |
| **语音克隆** | 从短样本零样本建立声音身份 | 个性化 |
| **风格迁移** | 对生成的语气、节奏与情绪进行控制 | 表现力 |

## 创作工作台

语音在此不再转瞬即逝，而成为可塑的素材。工作台把对话变为创作。

- **多轨时间线** — 在多语音时间线上编排对话、播客与叙事。
- **对话驱动编辑** — 说出修改，智能体重塑音频。无需鼠标。
- **版本谱系** — 每一次生成都保留源头。可分支、可变体、可回溯。
- **按智能体绑定语音** — 为每个智能体固定一种声音，始终知道是谁在说话。
- **语音人格** — 为任意语音附加自由形式的人格描述，智能体依此入戏表达。

## 使用场景

#### 日常陪伴

一个贯穿整日的声音。它记得你今晨提过的事，接上昨日对话的线索，以懂你的人的节奏说话。不是你召唤的助手——是你与之共处的在场。这是语音原生陪伴最贴近人的一面：一个握住你日子线索的伙伴。

#### 语音创作

一个栖居于对话中的工作台。描述你想要的声音，智能体把它谱写出来；说出修改，智能体就地重塑音频。多轨时间线、语音克隆、按智能体的人格——全部由对话驱动。引擎不取代你的工艺——它放大它，处理机械的部分，让你专注在那一点火花上。

#### 全场景工作

一个跨越 Web、桌面、移动端跟随上下文的声音。出行时口述，桌前精修，把任务交给智能体而你专注他处——后台任务与对话并行，结果就绪时回到对话。不是"语音辅助工作"——只是**工作**，多了一位从不停止倾听的队友。

#### 智能体构建

一个面向语音原生智能体的运行时。接入你自己的模型、工具、MCP 服务与技能，Melo 用语音把它们编排起来。全双工对话、并行任务执行、长期记忆提供基底——你带来智能。一个探索新型语音驱动智能体交互与人机协作未来的实验场。

## 哲学

Melo 坚持一个朴素信念：下一个计算时代是说来过，不是打出来。我们在探索与智能声音共生的意义——与它们共创、与它们同思、让在场取代屏幕。

对话不因工作而暂停。工作回到对话里。新的交互范式不是靠叠加功能建成的，而是靠缩短距离。
